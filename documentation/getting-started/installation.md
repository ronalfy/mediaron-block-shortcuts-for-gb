# Installation

Install and activate GenerateBlocks before this plugin. GenerateBlocks Pro is optional. Install it when you want the full admin-bar menu or Asset Library capture.

## Requirements

- WordPress 7.0 or later
- PHP 8.2 or later
- GenerateBlocks
- GenerateBlocks Pro (optional)

## Install the plugin

1. Install GenerateBlocks and activate it.
2. Copy this plugin into `wp-content/plugins/mediaron-block-shortcuts-for-gb`, or upload a release ZIP from **Plugins → Add New → Upload Plugin**.
3. Activate **MediaRon Block Shortcuts for GenerateBlocks**.
4. Open **GenerateBlocks → Shortcuts**.

Only Administrators can open the Shortcuts screen.

## What's next

- [Finding the Shortcuts settings](finding-the-settings.md) explains each panel.
- [Block menu tools](../editor/block-menu-tools.md) are available in the editor as soon as the plugin is active. They do not have a separate on/off switch, except the 1.x to 2.x conversion, which you turn on under Block Settings.
