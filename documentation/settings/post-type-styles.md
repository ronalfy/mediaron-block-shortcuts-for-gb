# Post Type Styles

Open **GenerateBlocks → Shortcuts** and use the **Post Type Styles** panel.

Check the post types that should receive GenerateBlocks styles. Uncheck a post type to leave GenerateBlocks styles off for that type.

Posts and pages are checked by default. Any other public post type on the site is listed by its label and is unchecked until you select it.

Select **Save Options** after you change the list.

This does not delete styles already saved on a block. It controls whether GenerateBlocks processes content for that post type.
